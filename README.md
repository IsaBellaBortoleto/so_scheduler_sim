# Simulador de SO Multitarefa
Esse trabalho foi desenvolvido em três partes: A, B e C. Em seguida, segue uma explicação breve de cada parte.

## Projeto A

  O Projeto A consiste em um simulador de sistema operacional multitarefa preemp
tivo de tempo compartilhado, com vários processadores, os algoritmos de escalona
mento Rate Monotonic e Earliest Deadline First e a visualização da execução em
um gráfico de Gantt.
  O simulador está sendo escrito em C, com a interface exibida no navegador, e
será entregue como um único executável, que roda sem a instalação de bibliotecas
ou programas adicionais.

### Compilação/Execução
1. Primeira opção:
Utilize-se no terminal com a pasta do projeto o seguinte comando:

|            Comando           |                    O que faz?                       |
| ---------------------------- | --------------------------------------------------- |
|     ``make``                 | compila e gera o simulador.exe                      |
| ``./simulador.exe``          |  abre o simulador no navegador                      |
| `` ./simulador.exe --teste`` |  roda os testes automaticos, sem abrir o navegador  |
